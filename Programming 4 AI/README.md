# Programming 4 AI

## Introduction
This repository contains my 8 Python lab tasks completed as part of the Programming for Artificial Intelligence course.

These lab tasks focus on learning the fundamentals of Python programming and developing basic programming skills through practical exercises.

## Topics Covered

### 1. Python Basics
Introduction to Python programming, basic syntax, and writing simple Python programs.

### 2. Variables and Data Types
Understanding variables, storing values, and working with different data types in Python.

### 3. Conditional Statements
Using `if`, `elif`, and `else` statements to make decisions in Python programs.

### 4. Loops
Using `for` and `while` loops to repeat instructions and perform repetitive tasks.

### 5. Functions
Creating and calling functions to organize code and reuse instructions.

### 6. Operators and Expressions
Working with arithmetic, comparison, and logical operators to perform different operations.

### 7. Input and Output
Taking input from users and displaying results using Python's input and print functions.

### 8. Practical Programming Exercises
Solving different programming problems by applying basic Python concepts.

## Objective
The main objective of these lab tasks is to build a strong foundation in Python programming and understand how different programming concepts are used to solve problems.
