# Python Programming Assignments

This repository contains five Python programs designed to practice basic Python programming concepts, including functions, loops, conditional statements, lists, dictionaries, sets, and file handling.

## Q1: Student Result Management System
This program manages the results of five students. It takes each student's name, roll number, and marks in Python, Artificial Intelligence, and Mathematics. It stores student information in dictionaries and a list. A function calculates the total marks, percentage, and grade of each student. The program displays all student results, finds the student with the highest percentage, and saves the final results in `results.txt`.

**Concepts Used:** Lists, Dictionaries, Functions, Loops, Conditional Statements, File Handling.

## Q2: Sentence Analysis Program
This program takes a sentence from the user and analyzes it. It counts the total number of words and characters, finds the longest and shortest words, counts vowels, creates a set of unique words, and displays the words in alphabetical order. The complete analysis is saved in `word_analysis.txt`.

**Concepts Used:** Strings, Lists, Sets, Functions, Loops, File Handling.

## Q3: Shopping and Billing System
This program takes information about five products, including product names, prices, and quantities. It calculates the total price of each product and the complete bill. If the bill exceeds Rs. 10,000, a 10% discount is applied. The program also identifies the most expensive product and saves the final bill in `bill.txt`.

**Concepts Used:** Dictionaries, Functions, Loops, Conditional Statements, Arithmetic Operations, File Handling.

## Q4: Simple Calculator
This program works as a basic calculator. It takes two numbers from the user and allows them to select an operation: addition, subtraction, multiplication, division, or modulus. Separate functions perform the calculations. The program continues running until the user chooses to exit.

**Concepts Used:** Functions, If-Elif-Else Statements, Loops, User Input, Arithmetic Operations.

## Q5: Restaurant Ordering System
This program provides a restaurant menu containing burgers, pizzas, fries, and drinks with their prices. Customers can select multiple items and enter the quantity of each item. The program calculates the price of each order and generates the final bill.

**Concepts Used:** Lists or Dictionaries, Loops, Conditional Statements, User Input, Arithmetic Operations, Functions.

## Objectives
- Practice basic Python programming.
- Understand the use of functions and data structures.
- Perform calculations using conditional statements and loops.
- Store and manage data using lists, dictionaries, and sets.
- Learn how to save program results in text files.

## Language
- Python 3
